# 《格式塔》(Gestalt) - 生物机械构装解谜

基于 Godot 4 (GDScript) 实现的生物机械建筑解谜游戏。

## 游戏总体概念

在《格式塔》(Gestalt) 的微观世界中，玩家将作为母巢构装师，利用各种分化细胞与生物机械器官，在离散的网格空间内搭建刚体机械。所有方块每一时刻同时行动，通过精密的时序与结构配合，完成清除污染病原体、捕获高能质粒核心等关卡任务。

## 游戏系统与操作指南

### 1. 核心控制键位
- **视角移动 (Pan)**: `W / A / S / D` 或按住 `鼠标中键` 拖拽画布；移动端支持双指平移。
- **视角缩放 (Zoom)**: `鼠标滚轮`（缩放中心严格锚定在鼠标光标所在世界坐标）；移动端支持双指捏合缩放（Pinch-to-zoom）。
- **方块放置 / 擦除**:
  - `鼠标左键`: 在允许建造区域内放置方块（支持按住拖动连续放置）。
  - `鼠标右键`: 擦除方块（支持按住拖动连续擦除；游玩模式下关卡内置地形受保护无法被直接擦除）。
- **旋转与翻转**:
  - `Q / E`: 逆时针 / 顺时针旋转 90°（未放置时旋转预览，有选中方块时同时旋转所选方块）。
  - `F`: 翻转方块子模式（例如切换转向器的顺时针 [CW] / 逆时针 [CCW] 模式）。
- **方块选择与多选拖拽**:
  - `数字键 1 ~ 6`: 快捷切换放置 1:普通方块、2:抑制器、3:推动器、4:复制器、5:摧毁器、6:转向器。
  - `V 键`: 切换为指针选择工具。
  - `鼠标左键`: 单击选中方块。
  - `Shift + 左键`: 加选 / 连选多个方块。
  - `拖拽矩形框`: 批量框选区域内的方块。
  - `右键拖拽选中组`: 选中一组方块后，按住右键直接在网格上整体验证与平移拖动。
- **结构成组 (Structure Grouping)**:
  - `G 键`: 将选中的方块绑定为一个刚体整体结构（美术上将自动擦除结构内部连通的边缘边框，形成统一的有机细胞膜）；若已成组则再次按 G 可解组。
- **模拟控制**:
  - `空格键 (Space)`: 开始 / 暂停离散时间模拟。
  - `单步 (Step)`: 执行单次离散周期。
  - `重置 (Reset)`: 一键还原到模拟启动前的初始构装状态。
  - `速度滑块`: 支持 `0.2x ~ 2.0x` 动画速率无级微调。

## 方块类型与行为规则

### 玩家机械方块 (快捷键 1 ~ 6)
1. **普通方块 [1]**: 机械的基础骨架，提供连接与传动支撑。
2. **抑制器 [2]**: 朝向一侧检测到任意方块时，反向一格方块暂时失去全部功能与特性。
3. **推动器 [3]**: 推动自身及前方结构前进一格。
   - 同向推动器合力推移，不产生冲突；
   - 逆向推动器互相对峙，自动取消位移；
   - 非共线（正交）推动器作用于同一目标时，驱动目标沿合成向量斜向移动。
4. **复制器 [4]**: 若后方存在方块且前方为空，将后方方块克隆至前方并保持朝向（复制出的方块不继承结构；若多个复制器写入同一空格，由真随机数发生器公平决选）。
5. **摧毁器 [5]**: 朝向前方有方块时，摧毁目标方块。
6. **转向器 [6]**: 分为顺时针 (CW) 与逆时针 (CCW) 模式（按 F 切换），将指向的方块旋转 90°；多个转向器作用于同一目标时，旋转角度直接代数相加。

### 世界关卡方块 (编辑器快捷键 7 ~ 0)
7. **坚硬方块 [7]**: 天然免疫摧毁、复制与推动；**但若被抑制器抑制，则立即丧失免疫性！**
8. **游荡怪物 [8]**: 沿朝向自主巡逻；遇到 1 格高台阶可向上跳跃，悬崖边缘会自动掉落，无路可走时调头转向；撞击其他方块时会对其造成接触伤害（每块方块初始生命值 HP=2）。
9. **宝藏 [9]**: 关卡目标核心，需由机械运回玩家建造区域内完成回收。
0. **污染源 [0]**: 关卡病原体，必须全部被摧毁才能通关。

## 启动与调试

在终端运行根目录启动脚本：
```bash
./start_web.sh
```
该脚本会自动检测 Godot 4 引擎、构建 Web 导出产物，并启动带有 COOP/COEP 隔离的本地 Web 服务器。启动后访问 `http://localhost:8060` 即可在浏览器游玩。

```
res://

│   ├── levels/          # 内置关卡配置 JSON (关卡 1 ~ 4)

│       ├── blocks/      # 矢量的生物主题 SVG 纹理 (inner, border, overlay, variants)
│       └── ui/          # 统一风格的矢量 UI 图标 (Play, Step, Reset, Save, Load 等)
├── scenes/
│   └── ui/
│       ├── MainMenu.tscn     # 主界面
│       ├── LevelSelect.tscn  # 关卡目录与选关卡片
│       ├── LevelPlayer.tscn  # 核心游玩与机械工坊界面
│       ├── LevelManager.tscn # 关卡管理器 (顺序调整/属性配置)
│       └── LevelEditor.tscn  # 全功能关卡编辑器 (支持放置世界方块与测试)
└── scripts/
    ├── core/
    │   ├── BlockData.gd        # 方块数据结构与序列化
    │   ├── GridWorld.gd        # 网格世界容器与结构管理
    │   ├── SimulationEngine.gd # 离散时间与物理/生物互动模拟核
    │   ├── LevelData.gd        # 关卡定义
    │   └── SaveManager.gd      # 关卡与图纸独立持久化
    ├── view/
    │   ├── BlockView.gd        # 邻域自适应细胞膜边界合并与补间动画
    │   ├── GridView.gd         # 世界画布、选框与幽灵预览
    │   └── CameraController.gd # 光标锚定平滑缩放与 WASD 平移
    └── ui/
        ├── MainMenu.gd
        ├── LevelSelect.gd
        ├── LevelManager.gd
        ├── LevelEditor.gd
        ├── LevelPlayer.gd
        ├── Toolbar.gd
        ├── VictoryDialog.gd
        └── BlueprintDialogs.gd
```
